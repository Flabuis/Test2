# «Каталог» — фан-адаптация The Mandela Catalogue (Alex Kister)

Неофициальная фан-адаптация по мотивам аналогового хоррора **The Mandela Catalogue** (автор оригинала — Alex Kister).
Экранизируем общую картину: округ Мандела, альтернаты, экстренные оповещения. **Сюжетную линию Марка (и Сезара) не берём.**
Тексты пишем своими словами, реплики оригинала дословно не переносим.

## Формат серии: история на кассете — до 2:00, интро и аутро сверху
1. **Интро, 14 с — общее** (`common/stage.js`, звук в `common/sfxlib.py: intro`):
   титр «по мотивам THE MANDELA CATALOGUE, автор оригинала — Alex Kister, неофициальная фан-адаптация» →
   тёмная комната, телевизор-видеодвойка с белым шумом, ряд кассет «ТОМ 1…6» под лампой, надпись THE MANDELA CATALOGUE →
   рука берёт кассету нужного тома и вставляет → PLAY → наезд в экран.
2. **Серия** (`epNN/episode.js`), запись с VHS: OSD «PLAY ▶», дата, полосы трекинга, субтитры.
3. **Аутро, 7 с — общее**: отъезд от экрана в комнату, шум, кассета выезжает, свет гаснет, темнота.

Интро и аутро меняем редко — правки в `common/` сразу действуют на все серии.
У аутро есть необязательный крючок серии: `episode.js` может экспортировать `outroHook(t, scene)` и добавить что-то в комнату
(том 2: когда гаснет лампа, в темноте на секунду проступает нарушитель). Без крючка аутро одинаковое.
У интро тоже есть варианты: `intro(t, ctx, epFrame, vol, {cut, hook})`. `cut` — время склейки: рука пропадает, кассета вставляется сама;
`hook(t, scene)` — крючок серии (том 3: после склейки за полкой стоит тёмный человек с красными глазами);
`hand: {blood, missing}` — вид руки (том 4: в крови, без указательного пальца). Без опций интро обычное.
У аутро ещё есть `screenFn(t, g)` — что показывает экран после того, как кассета выехала (том 4: улыбка).
С тома 4 по сюжету сигнал пытается захватить и наш телевизор — можно развивать в интро/аутро следующих томов.

## Стиль
PS1 low-poly (скилл `low-poly-motion`, PS1-вариант): 320×240, дрожащие вершины, flat shading, 15 FPS, дизер.
Шрифт — PT Mono. Ночь, холодный свет телевизора против тёплых фонарей.

## Голос
RHVoice, обработка в `common/voice.py`:
- `R` — диктор: `aleksandr-hq`, грубый мужской голос (ниже, хрипотца, лёгкий перегруз), интонация живая;
- `A` — альтернат: `yuriy`, ниже, плавающая высота, сдвинутые форманты, эхо;
- `M` — живой человек на любительской записи (видеокамера): `mikhail`, полоса микрофона;
- `X` — диктор с искажениями (проседает, заикается, хрустит); `S` — диктор, который всё сильнее замедляется;
- `F` — голос по телефону/автоответчику: `elena`, телефонная полоса; `W` — тот же голос «не тот»: ниже, плывёт, медленнее.

## Структура и пайплайн
```
mandela/
  render.js            node render.js epNN [--stills 5,15]
  vendor/              three.js
  common/core.js       рендерер, материалы, люди, текст, VHS, дизер
  common/stage.js      интро и аутро
  common/sfxlib.py     синтез звуков + звук интро/аутро
  common/voice.py      озвучка по vo/lines.tsv
  epNN/episode.js      серия: VOL, D (длина), CAPS (субтитры = реплики), drawEp(t, ctx)
  epNN/index.html      сборка интро + серия + аутро
  epNN/sfx.py          звук серии → sfx.wav
  epNN/vo/lines.tsv    реплики: начало, конец, кто (R/A), текст — время от начала серии
  epNN/ozvuchka.sh     голос + звук → epNN-ozvuchka.mp4
```
1. Сцена и субтитры → `episode.js`, реплики → `vo/lines.tsv` (те же тайминги).
2. Проверка кадров: `node render.js epNN --stills ...`
3. `python3 epNN/sfx.py`, `node render.js epNN`, `bash epNN/ozvuchka.sh`.

Длина истории D ≤ 120 с (интро 14 с и аутро 7 с в неё не входят). Том 1 — ещё по старому правилу (D = 96, весь ролик ≤ 2:00).
